# KBLI 2025

| Endpoint | Operation | Description |
|---|---|---|
| `GET /v1/kbli/categories` | `kbli.categories` | Top-level categories |
| `GET /v1/kbli/codes` | `kbli.list` | Paginated code directory |
| `GET /v1/kbli/codes/{code}` | `kbli.detail` | One 1–5 digit code |

List parameters: `page` defaults to 1 (maximum 10,000), `size` defaults to 20 (maximum 100), `level` is 1–5, `parent` filters by parent code, and `q` searches titles with a 100-character maximum.
