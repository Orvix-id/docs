# Universities Indonesia

- **Scope:** `universities:read` or `api_store:all`
- **Price:** free
- **Source:** SumoPod API Services (named in `meta.source`)
- **Daily limit:** 1,000 calls per organization in a rolling 24 hours, shared with [Hospitals Indonesia](/api-store/hospitals-indonesia). Past that, calls return `429` and `daily_limit_exceeded`.

| Endpoint | Operation | Description |
|---|---|---|
| `GET /v1/universities` | `universities.list` | Paginated university directory |
| `GET /v1/universities/{id}` | `universities.detail` | One university by provider ID |

```bash
curl "https://api.orvix.id/v1/universities?search=Indonesia&group=PTN&size=20" \
  -H "Authorization: Bearer $ORVIX_API_KEY"
```

## List parameters

| Query | Default | Constraint |
|---|---:|---|
| `page` | `1` | 1–100,000 |
| `size` | `20` | 1–100 |
| `search` | empty | Maximum 100 characters |
| `province_code`, `regency_code` | empty | Kemendagri region codes, as returned by [Regional Indonesia](/api-store/regional-indonesia) |
| `group` | empty | `PTN` (state), `PTS` (private), `PTA` (religious affairs), or `PTK` (service academy) |
| `type` | empty | Passed to the provider; maximum 64 characters |

Pagination is returned in `meta.pagination`.

## Detail

`id` is 1–12 digits. It belongs to the provider's dataset, is **not** a PDDikti institution code, and can change when the provider reloads its data. Do not store it as a permanent key. An unknown ID returns `404` and `not_found`.

## Errors

| Status | Code | Meaning |
|---|---|---|
| `400` | `invalid_request_error` | A parameter or ID failed validation |
| `404` | `not_found` | No university with that ID |
| `429` | `daily_limit_exceeded` | The organization used its 1,000 daily calls |
| `502`, `504` | `upstream_error`, `upstream_timeout` | The provider failed or timed out |
| `503` | `upstream_unavailable`, `upstream_not_configured`, `metering_error` | The provider is unavailable or out of quota, or usage metering is down |
