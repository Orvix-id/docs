# Regional Indonesia

| Endpoint | Operation | Description |
|---|---|---|
| `GET /v1/regions/provinces` | `provinces.list` | List provinces |
| `GET /v1/regions/provinces/{province_id}` | `provinces.detail` | Province detail |
| `GET /v1/regions/provinces/{province_id}/regencies` | `regencies.lookup` | Regencies in a province |
| `GET /v1/regions/regencies/{regency_id}` | `regencies.detail` | Regency detail |
| `GET /v1/regions/regencies/{regency_id}/districts` | `districts.lookup` | Districts in a regency |
| `GET /v1/regions/districts/{district_id}` | `districts.detail` | District detail |
| `GET /v1/regions/districts/{district_id}/villages` | `villages.lookup` | Villages in a district |
| `GET /v1/regions/villages/{village_id}` | `villages.detail` | Village detail |
| `GET /v1/regions/postal-codes?province=...&regency=...&district=...&village=...` | `postal-codes.search` | Exact hierarchical address search |
| `GET /v1/regions/postal-codes/{postal_code}` | `postal-codes.lookup` | Five-digit postal code lookup |

Region IDs are digits only, with a fixed length per level: province 2 (`31`), regency or city 4 (`3171`), district 7 (`3171010`), village 10 (`3171010001`). Any other ID returns `400`; a well-formed ID that does not exist returns `404` and `not_found`. Postal codes must contain exactly five digits. Postal-code search requires all four address parameters (maximum 150 characters each). Matching is case-insensitive and tolerates common `Kota`, `Kabupaten`, `Kab.`, and `Administrasi` prefixes. Results may contain multiple locations. The postal dataset is hosted by Orvix and derived from `sooluh/kodepos` under Apache-2.0; no runtime request is sent to that service.
