# Quickstart

## 1. Get an API key

Create a key from the [Orvix Platform](https://platform.orvix.id/api-keys). Your key starts with `orv-sk_live_`.

## 2. Install an SDK (optional)

You can use `fetch` directly on Node.js 18+. If you prefer an SDK:

```bash
# Node.js
npm install openai

# Python
pip install openai
```

## 3. Make your first request

### Using the OpenAI SDK (recommended)

```js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "orv-sk_live_...",
  baseURL: "https://api.orvix.id/v1",
});

const completion = await client.chat.completions.create({
  model: "gpt-4.1-mini",
  messages: [{ role: "user", content: "Hello from Orvix!" }],
});

console.log(completion.choices[0].message.content);
```

### Using fetch

```js
const response = await fetch("https://api.orvix.id/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: "Bearer orv-sk_live_...",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4.1-mini",
    messages: [{ role: "user", content: "Hello from Orvix!" }],
  }),
});

const data = await response.json();
console.log(data.choices[0].message.content);
```

### Using curl

```bash
curl https://api.orvix.id/v1/chat/completions \
  -H "Authorization: Bearer orv-sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4.1-mini",
    "messages": [{"role": "user", "content": "Hello from Orvix!"}]
  }'
```

## 4. List available models

```bash
curl https://api.orvix.id/v1/models \
  -H "Authorization: Bearer orv-sk_live_..."
```

That's it — you're routing AI requests through Orvix.
