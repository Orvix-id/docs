# OpenCode Setup

> **Endpoint note:** the general Orvix API is `https://api.orvix.id/v1`. Orvix Coding Plan's native
> route remains `POST /coding/completions` (required `session_id`; use [Kamui](https://github.com/ManifoldSystems/kamui)).
> OpenAI-compatible Coding Plan clients that append `/chat/completions` should use
> `https://api.orvix.id/coding/v1` instead of `/v1`.

Copy the prompt below to any AI (even free Zen models like Big Pickle / DeepSeek V4 Flash) — the AI will set up Orvix automatically.

```txt
Task: Set up Orvix in OpenCode.

Steps:
1. Ask the user for their Orvix API key if not already provided. Keys are at platform.orvix.id/api-keys, format orv-sk_live_... If they don't have one, direct them there.
2. Create file ~/.config/opencode/opencode.json (macOS/Linux) or %APPDATA%\opencode\opencode.json (Windows). Create the folder if needed: mkdir -p ~/.config/opencode.
3. Fill it with this config, replacing orv-sk_live_... with the user's key:
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "orvix": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Orvix",
      "options": {
        "baseURL": "https://api.orvix.id/v1",
        "apiKey": "orv-sk_live_..."
      },
      "models": {
        "orvix/muse-spark-1.2": {
          "name": "Muse Spark 1.2",
          "id": "orvix/muse-spark-1.2",
          "limit": {
            "context": 1000000,
            "output": 32000
          },
          "modalities": {
            "input": ["text", "image"],
            "output": ["text"]
          }
        }
      }
    }
  }
}
4. If the file already exists, merge provider.orvix without removing other providers. Validate JSON: python3 -m json.tool ~/.config/opencode/opencode.json.
5. Tell the user to restart OpenCode (config is only read at startup), then /models → select Orvix → Muse Spark 1.2.

Notes:
- Package must be @ai-sdk/openai-compatible (not @ai-sdk/openai). OpenCode appends `/chat/completions` to the baseURL.
- General Orvix API: `"baseURL": "https://api.orvix.id/v1"` with an `ai:invoke` key.
- Coding Plan: `"baseURL": "https://api.orvix.id/coding/v1"` with a `coding:invoke` key and an active Coding Plan. That calls `POST /coding/v1/chat/completions` and `GET /coding/v1/models`. Native `POST /coding/completions` stays for Kamui and still requires `session_id`.
- OpenCode does not send `session_id`. Compatibility requests still bill as Coding Plan, but cache affinity is disabled unless the client includes `session_id`. For the native sticky route, install Kamui from [kamui-web.vercel.app](https://kamui-web.vercel.app) and choose **Orvix Coding**.
- Model id must have orvix/ prefix (e.g., orvix/muse-spark-1.2). Without it you'll get no BYOK route error.
- modalities input ["text","image"] enables image understanding — without it clipboard images are rejected.
- For security, offer to move the key to env: "apiKey": "{env:ORVIX_API_KEY}" + export ORVIX_API_KEY="..." in ~/.zshrc.
- If error 402 = out of credits, direct to platform.orvix.id/billing.
- If error accepts at most 128 tools = OpenAI model limit, suggest orvix/muse-spark-1.2 or orvix/auto which have no tool limit.
```
