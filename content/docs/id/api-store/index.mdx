# API Store

API Store menyediakan sebelas produk data Indonesia dan ekstraksi dokumen di `https://api.orvix.id/v1`. Gunakan API key project Orvix dengan scope produk atau `api_store:all`.

```bash
curl https://api.orvix.id/v1/regions/provinces \
  -H "Authorization: Bearer $ORVIX_API_KEY"
```

## Produk dan scope

| Produk | Product ID | Scope | Harga | Sumber |
|---|---|---|---|---|
| [Regional Indonesia](/id/api-store/regional-indonesia) | `regional-indonesia` | `regions:read` | Gratis | API Wilayah Indonesia / Emsifa |
| [Indonesia Schools](/id/api-store/schools-indonesia) | `schools-indonesia` | `schools:read` | Gratis | Kemendikdasmen |

| [BMKG Indonesia](/id/api-store/bmkg-indonesia) | `bmkg-indonesia` | `bmkg:read` | Gratis | Data terbuka BMKG |
| [KBLI 2025](/id/api-store/kbli-indonesia) | `kbli-indonesia` | `kbli:read` | Gratis | BPS KBLI 2025 |
| [NIK Parser Indonesia](/id/api-store/nik-parser-indonesia) | `nik-parser-indonesia` | `nik:read` | Gratis | Snapshot legacy kode administrasi yang di-host Orvix |
| [Hospitals Indonesia](/id/api-store/hospitals-indonesia) | `hospitals-indonesia` | `hospitals:read` | Gratis, 1.000 call/hari | SumoPod API Services |
| [Universities Indonesia](/id/api-store/universities-indonesia) | `universities-indonesia` | `universities:read` | Gratis, 1.000 call/hari | SumoPod API Services |

`api_store:all` membuka semua produk di atas, tetapi tidak pernah membuka AI, Coding, atau Domains.

## Harga dan batas

Produk berbayar memotong saldo organisasi saat call diterima. Call yang sukses tetap ditagih; setiap call yang gagal di-refund penuh. Call tanpa saldo cukup mengembalikan `402` dan `insufficient_balance` sebelum ada proses apa pun. Produk gratis tidak pernah menyentuh saldo.

Setiap call, gratis maupun berbayar, dicatat ke usage project agar produk, operation, latensi, dan status dapat diobservasi. Harga dikelola server; client tidak boleh menyimpulkan billing dari body.

Hospitals Indonesia dan Universities Indonesia berbagi 1.000 call per organisasi dalam 24 jam bergulir (`429`, `daily_limit_exceeded`). KTP OCR dan NPWP OCR mengizinkan 8 gambar yang ditolak per organisasi per jam (`429`, `too_many_rejected_images`, dengan `Retry-After`).

## Contoh kode

Key harus memiliki scope produk terkait atau `api_store:all`. Semua contoh memakai satu client kecil dengan tiga fungsi:

- `get` untuk produk data, dengan filter di query string.
- `postJson` untuk NIK Parser. NIK dikirim di body agar tidak pernah muncul di URL atau access log. Contoh membacanya dari environment variable.
- `upload` untuk CV Extractor, KTP OCR, dan NPWP OCR, sebagai `multipart/form-data` di field `file`. Ekstraksi bisa lebih lama, jadi upload diberi timeout 120 detik.

Call berbayar (`cv`, `ktp`, `npwp`) masing-masing Rp300 jika sukses. Lihat halaman tiap produk untuk parameter dan field responsnya.

### cURL

```bash
# Produk data GET
curl "https://api.orvix.id/v1/schools?search=Jakarta&page=1&size=20" \
  -H "Authorization: Bearer $ORVIX_API_KEY"

curl "https://api.orvix.id/v1/hospitals?class=B&size=20" \
  -H "Authorization: Bearer $ORVIX_API_KEY"

# NIK Parser: body JSON, bukan URL
curl https://api.orvix.id/v1/nik/parse \
  -X POST \
  -H "Authorization: Bearer $ORVIX_API_KEY" \
  -H "Content-Type: application/json" \
  --data "{\"nik\":\"$NIK\"}"

# Ekstraksi dokumen: multipart field "file"
curl https://api.orvix.id/v1/ktp/extract \
  -H "Authorization: Bearer $ORVIX_API_KEY" \
  -F "file=@ktp.jpg"
```

### JavaScript

```js
import { readFile } from "node:fs/promises";

const BASE_URL = "https://api.orvix.id";
const auth = { Authorization: `Bearer ${process.env.ORVIX_API_KEY}` };

async function call(path, init = {}, timeoutMs = 15_000) {
  const response = await fetch(`${BASE_URL}${path}`, {
    ...init,
    headers: { ...auth, ...init.headers },
    signal: AbortSignal.timeout(timeoutMs),
  });
  const body = await response.json();
  if (!response.ok) {
    // Product errors carry error.code and meta.request_id; key and scope
    // failures use the AI shape with error.type and no meta.
    const code = body.error?.code ?? body.error?.type;
    const requestId = body.meta?.request_id ?? "no request id";
    const retry = response.headers.get("retry-after");
    throw new Error(
      `${response.status} ${code}: ${body.error?.message} (${requestId})` +
        (retry ? `, retry after ${retry}s` : ""),
    );
  }
  return body;
}

const get = (path, params = {}) =>
  call(`${path}?${new URLSearchParams(Object.entries(params).map(([k, v]) => [k, String(v)]))}`);

const postJson = (path, json) =>
  call(path, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(json),
  });

async function upload(path, filePath) {
  const form = new FormData();
  form.append("file", new Blob([await readFile(filePath)]), filePath.split("/").pop());
  return call(path, { method: "POST", body: form }, 120_000);
}

// Produk data gratis
const wilayah = await get("/v1/regions/provinces");
const sekolah = await get("/v1/schools", { search: "Jakarta", page: 1, size: 20 });
const libur = await get("/v1/holidays", { year: 2026 });
const gempa = await get("/v1/bmkg/earthquakes/latest");
const cuaca = await get("/v1/bmkg/weather", { adm4: "31.71.01.1001" });
const kbli = await get("/v1/kbli/codes", { q: "perangkat lunak", page: 1, size: 20 });
const rumahSakit = await get("/v1/hospitals", { search: "Harapan", class: "B", size: 20 });
const kampus = await get("/v1/universities", { group: "PTN", size: 20 });

// NIK Parser (gratis, POST)
const nik = await postJson("/v1/nik/parse", { nik: process.env.NIK });
const nikBatch = await postJson("/v1/nik/parse-batch", { niks: [process.env.NIK, "invalid"] });

// Ekstraksi dokumen (Rp300 per sukses)
const cv = await upload("/v1/cv/extract", "cv.pdf");
const ktp = await upload("/v1/ktp/extract", "ktp.jpg");
const npwp = await upload("/v1/npwp/extract", "npwp.jpg");
if (ktp.data.needs_review) console.warn(ktp.data.warnings);
```

### TypeScript

```ts
import { readFile } from "node:fs/promises";

type ApiStoreResponse<T> = {
  data: T;
  meta: {
    request_id: string;
    product: string;
    operation: string;
    source: unknown | null;
    pagination: { page: number; page_size: number; total_items: number } | null;
    cache: unknown | null;
  };
};

// Product errors carry error.code and meta; key and scope failures use the
// AI shape with error.type and no meta.
type ApiStoreError = {
  error: { code?: string; type?: string; message: string };
  meta?: { request_id: string; product: string; operation: string; upstream: unknown | null };
};

type Warning = { field: string; code: string; message: string };
type Correction = { field: string; dari: string | null; menjadi: string | null };
type Review = {
  needs_review: boolean;
  warnings: Warning[];
  koreksi: Correction[];
  referensi: Record<string, unknown>;
};
type Ktp = Review & { ktp: Record<string, string | null> };
type Npwp = Review & {
  npwp: Record<string, string | null>;
  alamat_baris: string[];
  detail: { npwp: Record<string, unknown> | null; nik: Record<string, unknown> | null };
};
type Cv = { cv: Record<string, unknown>; text: string };
type NikResult = { structurally_valid: boolean; provinsi: string | null; kota_kabupaten: string | null; issues: unknown[] };

const BASE_URL = "https://api.orvix.id";

class ApiStoreRequestError extends Error {
  readonly code: string;

  constructor(
    readonly status: number,
    readonly body: ApiStoreError,
    readonly retryAfterSeconds: number | null,
  ) {
    const code = body.error.code ?? body.error.type ?? "unknown_error";
    super(`${status} ${code}: ${body.error.message} (${body.meta?.request_id ?? "no request id"})`);
    this.code = code;
  }
}

async function call<T>(path: string, init: RequestInit = {}, timeoutMs = 15_000): Promise<ApiStoreResponse<T>> {
  const response = await fetch(`${BASE_URL}${path}`, {
    ...init,
    headers: { Authorization: `Bearer ${process.env.ORVIX_API_KEY}`, ...init.headers },
    signal: AbortSignal.timeout(timeoutMs),
  });
  const body = await response.json();
  if (!response.ok) {
    const retry = response.headers.get("retry-after");
    throw new ApiStoreRequestError(response.status, body as ApiStoreError, retry ? Number(retry) : null);
  }
  return body as ApiStoreResponse<T>;
}

const get = <T>(path: string, params: Record<string, string | number> = {}) =>
  call<T>(`${path}?${new URLSearchParams(Object.entries(params).map(([k, v]) => [k, String(v)]))}`);

const postJson = <T>(path: string, json: unknown) =>
  call<T>(path, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(json),
  });

async function upload<T>(path: string, filePath: string) {
  const form = new FormData();
  form.append("file", new Blob([await readFile(filePath)]), filePath.split("/").pop());
  return call<T>(path, { method: "POST", body: form }, 120_000);
}

const wilayah = await get<Array<{ id: string; name: string }>>("/v1/regions/provinces");
const sekolah = await get<unknown[]>("/v1/schools", { search: "Jakarta", page: 1, size: 20 });
const libur = await get<unknown[]>("/v1/holidays", { year: 2026 });
const gempa = await get<unknown>("/v1/bmkg/earthquakes/latest");
const cuaca = await get<unknown>("/v1/bmkg/weather", { adm4: "31.71.01.1001" });
const kbli = await get<unknown[]>("/v1/kbli/codes", { q: "perangkat lunak", page: 1, size: 20 });
const rumahSakit = await get<unknown[]>("/v1/hospitals", { search: "Harapan", class: "B", size: 20 });
const kampus = await get<unknown[]>("/v1/universities", { group: "PTN", size: 20 });

const nik = await postJson<NikResult>("/v1/nik/parse", { nik: process.env.NIK });
const nikBatch = await postJson<Array<{ data: NikResult | null; error: { code: string; message: string } | null }>>(
  "/v1/nik/parse-batch",
  { niks: [process.env.NIK, "invalid"] },
);

const cv = await upload<Cv>("/v1/cv/extract", "cv.pdf");
const npwp = await upload<Npwp>("/v1/npwp/extract", "npwp.jpg");
try {
  const ktp = await upload<Ktp>("/v1/ktp/extract", "ktp.jpg");
  if (ktp.data.needs_review) console.warn(ktp.data.warnings);
} catch (error) {
  if (error instanceof ApiStoreRequestError && error.code === "too_many_rejected_images") {
    console.warn(`Terlalu banyak gambar ditolak, coba lagi setelah ${error.retryAfterSeconds}s`);
  } else {
    throw error;
  }
}
```

### Python

```python
import os
from pathlib import Path

import requests

BASE_URL = "https://api.orvix.id"
session = requests.Session()
session.headers["Authorization"] = f"Bearer {os.environ['ORVIX_API_KEY']}"


class ApiStoreError(RuntimeError):
    def __init__(self, response: requests.Response):
        body = response.json()
        error, meta = body.get("error", {}), body.get("meta") or {}
        self.status = response.status_code
        # Product errors carry error.code and meta; key and scope failures
        # use the AI shape with error.type and no meta.
        self.code = error.get("code") or error.get("type")
        self.retry_after = response.headers.get("Retry-After")
        super().__init__(f"{self.status} {self.code}: {error.get('message')} ({meta.get('request_id', 'no request id')})")


def _check(response: requests.Response) -> dict:
    if not response.ok:
        raise ApiStoreError(response)
    return response.json()


def get(path: str, params: dict | None = None) -> dict:
    return _check(session.get(f"{BASE_URL}{path}", params=params or {}, timeout=15))


def post_json(path: str, payload: dict) -> dict:
    return _check(session.post(f"{BASE_URL}{path}", json=payload, timeout=15))


def upload(path: str, file_path: str) -> dict:
    with open(file_path, "rb") as file:
        files = {"file": (Path(file_path).name, file)}
        return _check(session.post(f"{BASE_URL}{path}", files=files, timeout=120))


# Produk data gratis
wilayah = get("/v1/regions/provinces")
sekolah = get("/v1/schools", {"search": "Jakarta", "page": 1, "size": 20})
libur = get("/v1/holidays", {"year": 2026})
gempa = get("/v1/bmkg/earthquakes/latest")
cuaca = get("/v1/bmkg/weather", {"adm4": "31.71.01.1001"})
kbli = get("/v1/kbli/codes", {"q": "perangkat lunak", "page": 1, "size": 20})
rumah_sakit = get("/v1/hospitals", {"search": "Harapan", "class": "B", "size": 20})
kampus = get("/v1/universities", {"group": "PTN", "size": 20})

# NIK Parser (gratis, POST)
nik = post_json("/v1/nik/parse", {"nik": os.environ["NIK"]})
nik_batch = post_json("/v1/nik/parse-batch", {"niks": [os.environ["NIK"], "invalid"]})

# Ekstraksi dokumen (Rp300 per sukses)
cv = upload("/v1/cv/extract", "cv.pdf")
npwp = upload("/v1/npwp/extract", "npwp.jpg")
try:
    ktp = upload("/v1/ktp/extract", "ktp.jpg")
    if ktp["data"]["needs_review"]:
        print(ktp["data"]["warnings"])
except ApiStoreError as error:
    if error.code != "too_many_rejected_images":
        raise
    print(f"Terlalu banyak gambar ditolak, coba lagi setelah {error.retry_after}s")
```

## Kontrak sukses

```json
{
  "data": [],
  "meta": {
    "request_id": "01...",
    "product": "schools-indonesia",
    "operation": "schools.list",
    "source": null,
    "pagination": { "page": 1, "page_size": 20, "total_items": 123 },
    "cache": null
  }
}
```

`source`, `pagination`, dan `cache` selalu ada dan `null` jika tidak berlaku. Header `x-request-id` mengulang `meta.request_id`. Key eksternal dinormalisasi rekursif ke `snake_case`; value tidak diubah. Contoh: `Infogempa` menjadi `data.info_gempa`, `DateTime` menjadi `date_time`.

## Kontrak error

```json
{
  "error": { "code": "upstream_timeout", "message": "Region provider timed out" },
  "meta": {
    "request_id": "01...",
    "product": "regional-indonesia",
    "operation": "provinces.list",
    "upstream": { "classification": "timeout" }
  }
}
```

`meta.upstream` selalu ada dan `null` untuk validation, metering, dataset lokal, serta not-found. Klasifikasi upstream: `timeout`, `unavailable`, atau `invalid_response`. Body upstream mentah dan error internal tidak diekspos.

Kegagalan key dan scope dijawab sebelum produk berjalan, dengan bentuk OpenAI-compatible seperti endpoint AI, tanpa `code` dan `meta`:

```json
{ "error": { "message": "Invalid API key prefix", "type": "authentication_error" } }
```

Key yang tidak ada, tidak dikenal, dicabut, atau tidak punya scope produk mengembalikan `401` dan `authentication_error`. Jika key sesaat tidak bisa dicek, API mengembalikan `503` dan `server_error` dengan `Retry-After`. Baca `error.code`, lalu `error.type` sebagai cadangan, seperti contoh di atas.

Code umum: `invalid_request_error`, `insufficient_balance`, `metering_error`, `not_found`, `dataset_not_available`, `dataset_error`, `daily_limit_exceeded`, `too_many_rejected_images`, `upstream_timeout`, `upstream_unavailable`, `upstream_not_configured`, dan `upstream_error`. Produk ekstraksi dokumen menambah code file seperti `file_required`, `file_too_large`, `unsupported_file_type`, `not_ktp`, dan `not_npwp`; lihat halamannya.

## Migrasi dari respons lama

- Baca record dari `data`, bukan root respons.
- Baca atribusi, pagination, dan cache dari `meta.source`, `meta.pagination`, dan `meta.cache`.
- Field pagination adalah `page`, `page_size`, dan `total_items`.
- Ganti `Infogempa`/`DateTime` menjadi `info_gempa`/`date_time`.
- Baca kegagalan dari `error.code` dan `error.message`; sertakan `meta.request_id` saat meminta bantuan.
