# Setup OpenCode

Plugin resmi [`@orvix-id/opencode`](https://github.com/Orvix-id/opencode-plugin) jalan di
OpenCode **1.18.29+** dan **2.0.21+**. Plugin ini mendaftarkan dua provider dan menjaga daftar
modelnya tetap sinkron dengan akun Anda:

| Provider | Dibayar dengan | Endpoint | Scope key |
| --- | --- | --- | --- |
| **Orvix Coding** (`orvix-coding/*`) | Coding Plan, AI Plan, campaign | `https://api.orvix.id/coding/v1` | `coding:invoke` |
| **Orvix** (`orvix/*`) | Orvix Credits, Token Plans | `https://api.orvix.id/v1` | `ai:invoke` |

<Callout type="warn">
  **Punya Coding Plan?** Pilih model dari **Orvix Coding** (nama berakhiran `(Orvix Coding)`). Model
  yang sama di bawah **Orvix** ditagih ke Orvix Credits dan gagal dengan `insufficient Orvix Credits`
  saat wallet kosong. Lihat [Setup Coding Plan](/id/coding-plan).
</Callout>

## 1. Buat key

Buka [platform.orvix.id/api-keys](https://platform.orvix.id/api-keys) dan buat key dengan scope
untuk provider yang Anda pakai: **Orvix Coding** (`coding:invoke`), **AI Router** (`ai:invoke`), atau keduanya.

## 2. Install plugin

Cek versi Anda dengan `opencode --version`.

**OpenCode 2.x:**

```bash
opencode plugin add @orvix-id/opencode
```

**OpenCode 1.x:** tambahkan plugin ke `~/.config/opencode/opencode.json` (merge dengan setting
yang sudah ada). OpenCode akan menginstallnya saat start berikutnya.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@orvix-id/opencode"]
}
```

v1 memakai `plugin` (tunggal), v2 memakai `plugins` (jamak). Anda tidak perlu blok `provider`:
plugin sudah mendaftarkan kedua provider. Jika Anda menyalin blok `provider.orvix` atau
`providers.orvix` dari versi lama halaman ini, hapus blok tersebut.

## 3. Set key

```bash
# Coding Plan
export ORVIX_CODING_API_KEY="orv-sk_live_..."

# General API (Orvix Credits)
export ORVIX_API_KEY="orv-sk_live_..."
```

Orvix Coding memakai `ORVIX_API_KEY` sebagai fallback jika `ORVIX_CODING_API_KEY` tidak di-set,
jadi key dengan kedua scope cukup memakai `ORVIX_API_KEY`. Taruh baris-baris ini di shell profile
(`~/.zshrc`, `~/.bashrc`) atau secret manager. Di OpenCode 2.x Anda juga bisa menjalankan
`/connect orvix-coding` atau `/connect orvix`; key yang tersimpan lebih diutamakan daripada environment.

## 4. Restart dan pilih model

Tutup OpenCode lalu jalankan lagi dari terminal yang sudah punya key:

```bash
opencode -m orvix-coding/deepseek-v4.1-flash   # Coding Plan
opencode -m orvix/deepseek-v4.1-flash          # Orvix Credits
```

Atau buka `/models` dan pilih model. Model yang punya level reasoning menyediakannya sebagai variant,
misalnya `orvix-coding/glm-5.2#high`.

## Biarkan AI yang setup

Paste ini ke assistant apa pun yang bisa mengedit file di mesin Anda:

```txt
Setup Orvix di OpenCode dengan plugin resmi @orvix-id/opencode.
1. Jalankan `opencode --version`.
2. Untuk 2.x jalankan `opencode plugin add @orvix-id/opencode`. Untuk 1.x tambahkan "@orvix-id/opencode"
   ke array "plugin" di ~/.config/opencode/opencode.json, merge dengan setting yang sudah ada.
3. Hapus blok "provider.orvix" atau "providers.orvix" dari file itu; plugin mendaftarkan
   provider-nya sendiri. Validasi JSON-nya setelah itu.
4. Minta key Orvix saya (platform.orvix.id/api-keys) lalu tambahkan
   export ORVIX_CODING_API_KEY="..." ke shell profile saya. Jangan tampilkan key-nya kembali.
5. Suruh saya restart OpenCode dan pilih model berakhiran "(Orvix Coding)" dari /models.
```

## Migrasi

- **Dari `opencode-provider-orvix`:** plugin komunitas ini sekarang sudah jadi bagian dari plugin resmi.
  Ganti di daftar plugin Anda dengan `@orvix-id/opencode`; pilihan model `orvix/*` dan `ORVIX_API_KEY`
  tetap berfungsi. Jangan load keduanya.
- **Dari config provider yang ditulis manual:** hapus blok `provider.orvix` (1.x) atau `providers.orvix`
  (2.x) lalu install plugin.

## Troubleshooting

| Gejala | Solusi |
| --- | --- |
| `insufficient Orvix Credits` padahal punya Coding Plan | Pilih model di bawah **Orvix Coding**, bukan **Orvix**. |
| `Unsupported package for orvix/...` | Ada blok provider yang ditulis manual untuk versi OpenCode yang lain. Hapus dan pakai plugin. |
| `Model unavailable: orvix-coding/...` | Cek `plugin`/`plugins`, restart, lalu baca `opencode --print-logs`. |
| Tidak ada model Orvix di `/models` | Key tidak ada di environment OpenCode, atau tidak punya scope provider tersebut. |
| `401 coding:invoke scope required` | Buat key dengan scope **Orvix Coding**. |
| `402` di **Orvix** | Tambah credits di [platform.orvix.id/billing](https://platform.orvix.id/billing). |
| `429 coding_quota_exceeded` | Jendela 5 jam, mingguan, atau bulanan sudah habis; `resets_at` menunjukkan kapan kembali. |

Error Coding Plan lainnya: [Setup Coding Plan](/id/coding-plan#troubleshooting).
