# Setup OpenCode

Copy prompt di bawah ke AI apapun (bahkan model free di Zen seperti Big Pickle / DeepSeek V4 Flash) — AI akan setup Orvix otomatis.

```txt
Tugas: Setup Orvix di OpenCode.

Langkah:
1. Minta API key Orvix ke user jika belum ada. Key ada di platform.orvix.id/api-keys, format orv-sk_live_... Jika user belum punya, arahkan ke sana.
2. Buat file ~/.config/opencode/opencode.json (macOS/Linux) atau %APPDATA%\opencode\opencode.json (Windows). Buat folder jika belum ada: mkdir -p ~/.config/opencode.
3. Isi dengan config ini, ganti orv-sk_live_... dengan key user:
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "orvix": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Orvix",
      "options": {
        "baseURL": "https://api.orvix.id/v1",
        "apiKey": "orv-sk_live_..."
      },
      "models": {
        "orvix/muse-spark-1.2": {
          "name": "Muse Spark 1.2",
          "id": "orvix/muse-spark-1.2",
          "limit": {
            "context": 1000000,
            "output": 32000
          },
          "modalities": {
            "input": ["text", "image"],
            "output": ["text"]
          }
        }
      }
    }
  }
}
4. Jika file sudah ada, merge provider.orvix tanpa hapus provider lain. Validasi JSON: python3 -m json.tool ~/.config/opencode/opencode.json.
5. Suruh user restart OpenCode (config hanya dibaca saat startup), lalu /models → pilih Orvix → Muse Spark 1.2.

Catatan:
- Paket harus @ai-sdk/openai-compatible (bukan @ai-sdk/openai). Orvix pakai /v1/chat/completions.
- Model id wajib prefix orvix/ (contoh: orvix/muse-spark-1.2). Tanpa prefix akan error no BYOK route.
- modalities input ["text","image"] mengaktifkan pemahaman gambar — tanpa itu clipboard image akan ditolak.
- Untuk keamanan, tawarkan pindah key ke env: "apiKey": "{env:ORVIX_API_KEY}" + export ORVIX_API_KEY="..." di ~/.zshrc.
- Jika error 402 = credits habis, arahkan ke platform.orvix.id/billing.
- Jika error accepts at most 128 tools = model OpenAI, sarankan orvix/muse-spark-1.2 atau orvix/auto yang tidak ada batas tool.
```
