# Image Generations

`POST /v1/images/generations`

Generate gambar berformat OpenAI. Debit = **Image Credits prabayar** (`PlanSpendScope::Image`) — bukan Ember token, bukan saldo IDR, bukan Coding / One.

Beli **Image Credits 100** di halaman Plans (100 kredit, 365 hari). Setiap model di katalog memuat `capabilities.imageCreditCost`.

## Katalog

| Model | Catatan |
|---|---|
| `flux-2-pro` | Black Forest Labs |
| `qwen-image-3.0` | Qwen (bukan Pro) |
| `seedream-5.0-pro` | ByteDance |
| `gpt-image-2` | OpenAI |
| `gemini-3-pro-image` | Google |
| `midjourney` | Midjourney Fast Imagine (satu grid 4 gambar; `n` harus 1) |
| `grok-imagine-image` | Grok Imagine (bukan SKU quality) |

Wan tidak ada di katalog ini.

Prefix `orvix/` diterima (`orvix/flux-2-pro`).

## Request body

| Field | Tipe | Wajib | Deskripsi |
|---|---|---|---|
| `model` | string | Ya | Slug katalog, dengan atau tanpa `orvix/` |
| `prompt` | string | Ya | Prompt tidak boleh kosong |
| `n` | integer | Tidak | `1`–`4` (default `1`). Gemini 3 Pro Image dan Seedream 5.0 Pro selalu 1. |
| `size` | string | Tidak | Ukuran piksel. GPT/Flux: `1024x1024`. Seedream: `2048x2048`. Qwen: `1024*1024` (`x` diubah otomatis). Gemini: `1K` / `2K` / `4K`. |
| `quality` | string | Tidak | Diteruskan jika upstream menerima |
| `response_format` | string | Tidak | `url` atau `b64_json` jika upstream mendukung |

Field tambahan diteruskan ke adapter upstream.

Untuk `gemini-3-pro-image`, kirim `aspect_ratio` (misalnya `16:9`) sebagai field tambahan. `size` menerima `1K`, `2K`, atau `4K`.

### Contoh

```json
{
  "model": "orvix/gemini-3-pro-image",
  "prompt": "Astronaut menunggang kuda di Mars, cahaya sinematik",
  "size": "1K",
  "aspect_ratio": "16:9",
  "n": 1
}
```

## Respons

```json
{
  "created": 1757200000,
  "model": "orvix/flux-2-pro",
  "data": [
    { "url": "https://is3.cloudhost.id/orvix/orvix-images/flux-2-pro-0-….png?X-Amz-Signature=…" }
  ]
}
```

API menyimpan gambar upstream ke object storage dan mengembalikan `data[].url`; base64 upstream tidak dikembalikan ke klien. Kredit baru didebit setelah penyimpanan berhasil.

Gambar tersimpan bersifat privat. `data[].url` adalah tautan bertanda tangan yang kedaluwarsa dalam 24 jam, jadi unduh berkasnya alih-alih menyimpan URL-nya. `GET /v1/images` menandatangani ulang setiap dipanggil, sehingga gambar lama tetap bisa diambil dengan tautan baru.

## cURL

```bash
curl https://api.orvix.id/v1/images/generations \
  -H "Authorization: Bearer orv-sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3-pro-image",
    "prompt": "Astronaut menunggang kuda di Mars, cahaya sinematik",
    "size": "1K",
    "aspect_ratio": "16:9"
  }'
```

## Error khusus permukaan ini

| HTTP | `type` | Kapan |
|---|---|---|
| 400 | `invalid_request_error` | Prompt kosong, `n` di luar 1–4, model bukan image |
| 402 | `insufficient_credits` | Image Credits habis (Ember / Coding / dompet tidak membayar) |
| 429 | `rate_limit_error` | Soft RPM pada model yang mempublikasikan kartu rendah (mis. Qwen) |
| 502 | `server_error` | Semua rute image gagal |

Coba di [playground Images](https://platform.orvix.id/images).
