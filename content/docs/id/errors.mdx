# Error

AI router mengembalikan error dalam format OpenAI:

```json
{
  "error": {
    "message": "Invalid API key signature",
    "type": "authentication_error"
  }
}
```

## Tipe error

| HTTP status | `type` | Deskripsi |
|---|---|---|
| 400 | `invalid_request_error` | Request salah format, model tidak dikenal, prefix `orvix/` tidak valid |
| 401 | `authentication_error` | API key tidak valid, kedaluwarsa, atau dicabut |
| 402 | `insufficient_credits` | Orvix Credits tidak cukup untuk model terkelola |
| 403 | `permission_error` | API key tidak diizinkan untuk sumber pendanaan yang diminta |
| 429 | `rate_limit_error` | Rate limit per-key atau limit belanja bulanan terlampaui |
| 502 | `server_error` | Semua rute provider upstream gagal |
| 503 | `server_error` | AI router belum dikonfigurasikan di deployment ini |
| 500 | `server_error` | Internal server error |

## Contoh error umum

### Model tidak dikenal

```json
{
  "error": {
    "message": "no enabled provider serves model 'gpt-5'",
    "type": "invalid_request_error"
  }
}
```

### Credits tidak cukup

```json
{
  "error": {
    "message": "insufficient credits",
    "type": "insufficient_credits"
  }
}
```

### Rate limit terlampaui

```json
{
  "error": {
    "message": "rate limit of 60 requests per minute exceeded",
    "type": "rate_limit_error"
  }
}
```

### Limit belanja bulanan

```json
{
  "error": {
    "message": "monthly spend limit of $50.00 reached ($50.12 used this month)",
    "type": "rate_limit_error"
  }
}
```

### Kegagalan upstream (502)

```json
{
  "error": {
    "message": "all routes failed for model 'gpt-4.1-mini'",
    "type": "server_error"
  }
}
```

## Error saat streaming

Selama streaming, jika terjadi error upstream di tengah stream, router akan mengirim event error alih-alih memutus koneksi:

```
data: {"error":{"message":"upstream timeout","type":"server_error"}}
data: [DONE]
```

## Menangani error

### JavaScript

```js
const response = await fetch("https://api.orvix.id/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: "Bearer orv-sk_live_...",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ model: "gpt-4.1-mini", messages: [...] }),
});

if (!response.ok) {
  const { error } = await response.json();
  console.error(`${error.type}: ${error.message}`);
  return;
}
```

### Python

```python
import requests

response = requests.post(
    "https://api.orvix.id/v1/chat/completions",
    headers={"Authorization": "Bearer orv-sk_live_..."},
    json={"model": "gpt-4.1-mini", "messages": [...]},
    timeout=60,
)

if not response.ok:
    error = response.json()["error"]
    raise RuntimeError(f"{error['type']}: {error['message']}")
```
