# Setup OpenCode V2

Panduan ini khusus untuk **OpenCode V2**. Jika masih memakai OpenCode versi sebelumnya, ikuti panduan [Setup OpenCode](/id/opencode).

## Persiapan

Buat API key Orvix di [platform.orvix.id/api-keys](https://platform.orvix.id/api-keys). Akses API umum membutuhkan key dengan izin `ai:invoke`.

Endpoint API umum:

```text
https://api.orvix.id/v1
```

## Konfigurasi provider

Buat atau edit config global:

- macOS/Linux: `~/.config/opencode/opencode.json`
- Windows: `%APPDATA%\opencode\opencode.json`

Merge `providers.orvix` ke file yang sudah ada tanpa menghapus setting lain:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "orvix": {
      "name": "Orvix",
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "https://api.orvix.id/v1",
        "apiKey": "{env:ORVIX_API_KEY}"
      },
      "models": {
        "orvix/gpt-5.6-sol": {
          "modelID": "orvix/gpt-5.6-sol",
          "name": "GPT 5.6 Sol",
          "capabilities": {
            "tools": true,
            "input": ["text", "image"],
            "output": ["text"]
          }
        },
        "orvix/auto": {
          "modelID": "orvix/auto",
          "name": "Orvix Auto",
          "capabilities": {
            "tools": true,
            "input": ["text", "image"],
            "output": ["text"]
          }
        }
      }
    }
  }
}
```

OpenCode V2 memakai `providers`, `package`, `settings`, `modelID`, dan `capabilities`. Jangan ganti dengan field legacy `provider`, `npm`, `options`, `id`, atau `modalities`.

## Simpan API key

Simpan key di environment background service:

```bash
opencode service set env ORVIX_API_KEY "orv-sk_live_..."
```

Cara ini lebih andal daripada hanya mengekspor key dari shell profile karena service OpenCode yang sudah berjalan mungkin tidak mewarisi variabel shell baru.

Periksa setting service tanpa membagikan nilainya:

```bash
opencode service get
```

## Validasi dan reload

```bash
python3 -m json.tool ~/.config/opencode/opencode.json
opencode reload
opencode models
```

Buka `/models` lalu pilih model Orvix. Selector seperti `orvix/orvix/gpt-5.6-sol` adalah normal: `orvix` pertama merupakan ID provider OpenCode, sedangkan `orvix/gpt-5.6-sol` adalah ID model upstream yang dikirim ke API.

## Tambahkan model lain

Ambil inventory terbaru dari `GET https://api.orvix.id/v1/models` dengan `Authorization: Bearer <key>`, lalu tambahkan model chat yang tersedia ke `providers.orvix.models`.

- Pertahankan prefix upstream `orvix/` secara lengkap pada map key dan `modelID`; menghapusnya dapat menyebabkan error no BYOK route.
- Jangan salin metadata capability Orvix secara langsung. Petakan ke field OpenCode `capabilities.tools`, `capabilities.input`, `capabilities.output`, dan `limit`.
- Konfigurasikan model khusus image dan video generation melalui API generation, bukan provider chat-completions ini.

## Coding Plan

Untuk klien OpenAI-compatible Coding Plan, gunakan `https://api.orvix.id/coding/v1` dengan key `coding:invoke` dan Coding Plan aktif. Endpoint ini memakai `POST /coding/v1/chat/completions` dan `GET /coding/v1/models`.

OpenCode tidak mengirim `session_id`. Untuk rute sticky native di `POST /coding/completions`, install [Kamui](https://kamui-web.vercel.app) lalu pilih **Orvix Coding**.

## Troubleshooting

- **Missing Authorization header:** jalankan `opencode service get`, pastikan `env.ORVIX_API_KEY` tersedia, lalu restart service.
- **402:** tambah credits di [platform.orvix.id/billing](https://platform.orvix.id/billing).
- **No BYOK route:** gunakan ID model upstream lengkap yang diawali `orvix/`.
- **Accepts at most 128 tools:** gunakan `orvix/gpt-5.6-sol` atau `orvix/auto`.
