# Config Manual OpenCode V2

<Callout type="warn">
  **Pakai plugin kalau bisa.** `opencode plugin add @orvix-id/opencode` mendaftarkan kedua provider
  Orvix, menjaga daftar model tetap terbaru, dan mengaktifkan prompt caching untuk Coding Plan. Lihat
  [Setup OpenCode](/id/opencode). Halaman ini untuk setup yang tidak bisa memuat plugin.
</Callout>

Config ini khusus untuk **OpenCode 2.x**. OpenCode 1.x memakai nama field yang berbeda; blok 2.x di
instalasi 1.x (atau sebaliknya) tidak akan ter-load, biasanya dengan error `Unsupported package`.

## Pilih endpoint dulu

| Anda bayar dengan | Base URL | Scope key | ID provider di bawah |
| --- | --- | --- | --- |
| Coding Plan atau AI Plan | `https://api.orvix.id/coding/v1` | `coding:invoke` | `orvix-coding` |
| Orvix Credits | `https://api.orvix.id/v1` | `ai:invoke` | `orvix` |

Mengarahkan key Coding Plan ke `/v1` akan menagih Orvix Credits, bukan plan, dan gagal dengan
`insufficient Orvix Credits` saat wallet kosong.

## Konfigurasi provider

Edit `~/.config/opencode/opencode.json` (macOS/Linux) atau `%APPDATA%\opencode\opencode.json`
(Windows). Merge ke file yang sudah ada tanpa menghapus setting lain. Perhatikan bahwa key top-level-nya
adalah `providers` (jamak).

**Coding Plan:**

```json
{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "orvix-coding": {
      "name": "Orvix Coding",
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "https://api.orvix.id/coding/v1",
        "apiKey": "{env:ORVIX_CODING_API_KEY}"
      },
      "models": {
        "deepseek-v4.1-flash": {
          "modelID": "orvix/deepseek-v4.1-flash",
          "name": "DeepSeek V4.1 Flash (Orvix Coding)",
          "capabilities": {
            "tools": true,
            "input": ["text", "image"],
            "output": ["text"]
          }
        }
      }
    }
  }
}
```

**Orvix Credits:** blok yang sama dengan ID provider `orvix`, base URL `https://api.orvix.id/v1`,
`"apiKey": "{env:ORVIX_API_KEY}"`, dan model dari `GET /v1/models`.

OpenCode 2.x memakai `providers`, `package`, `settings`, `modelID`, dan `capabilities`. Jangan campur
dengan field 1.x `provider`, `npm`, `options`, `id`, atau `modalities`.

## Simpan key

Simpan key di environment background service supaya service yang sudah berjalan ikut membacanya:

```bash
opencode service set env ORVIX_CODING_API_KEY "orv-sk_live_..."
opencode service get   # confirm it is set, without printing it elsewhere
```

## Validasi dan reload

```bash
python3 -m json.tool ~/.config/opencode/opencode.json
opencode reload
opencode models
```

Buka `/models` lalu pilih model. Selector-nya terbaca `orvix-coding/deepseek-v4.1-flash`: bagian
pertama adalah ID provider, sedangkan `modelID` adalah yang dikirim ke Orvix.

## Tambahkan model lain

Lihat daftar model yang bisa dipakai key Anda, lalu tambahkan masing-masing di bawah `models`:

```bash
curl https://api.orvix.id/coding/v1/models -H "Authorization: Bearer $ORVIX_CODING_API_KEY"
```

Pertahankan prefix `orvix/` secara lengkap di `modelID`. Set `capabilities.input` ke `["text", "image"]`
hanya untuk model yang menerima gambar. Model image dan video generation tidak termasuk di provider chat.

## Batasan config manual

Tanpa plugin, OpenCode tidak mengirim `session_id`, jadi request Coding Plan tetap ditagih ke plan
tetapi tidak kena prompt cache: setiap turn membayar prompt penuh. Daftar model juga tidak ikut
ter-update saat lineup model plan berubah.

## Troubleshooting

| Gejala | Solusi |
| --- | --- |
| `Unsupported package` | Config-nya untuk versi OpenCode yang lain. Cek `opencode --version`, atau pakai plugin. |
| `insufficient Orvix Credits` padahal punya Coding Plan | Base URL-nya `/v1`. Pakai `https://api.orvix.id/coding/v1`. |
| Missing Authorization header | Jalankan `opencode service get`, pastikan variabel key sudah di-set, lalu restart service. |
| `401 coding:invoke scope required` | Buat key dengan scope **Orvix Coding**. |
| No BYOK route | Pakai ID model lengkap yang diawali `orvix/` di `modelID`. |

Selengkapnya: [Setup Coding Plan](/id/coding-plan#troubleshooting).
